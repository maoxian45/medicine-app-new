## 调用方式

Vue → routers → services → repositories → SQLite。保留原接口路径和字段，Swagger 在 http://127.0.0.1:8000/docs 查看。

- routers 只保留接口声明和服务调用，FastAPI 完成请求模型校验。
- services 负责流程编排、解析及结果整理。
- repositories 接管现有 SQL 事务，当前保留少量旧实现中的对象一致性校验和 HTTPException，后续按模块逐步将业务校验返回给 services，不为分层再引入复杂框架。
- models 统一定义输入输出结构；原有 routers 的模型导入仍兼容旧测试。
- 前端用相对地址 /api，由 Vite 代理到 8000，不能硬编码个人电脑 IP。
- 错误保留 FastAPI 的 detail 格式；前端失败时保留表单，成功以服务器返回为准。
- 现阶段药箱使用 owner 名称关联，兼容原实现；改成 member_id 时四人统一接口与迁移，不能单方面改字段。

## 协作

一个文件一个负责人；接口变更先改约定，再由对应负责人修改自己的文件。先约定方法参数和返回值，各人使用自己的分支。各自详细设计描述实际代码，系统测试按功能场景汇总，不要求人为增加类或重复实现功能。
