## 本地演示账号

- 家庭：family / family-demo
- 管理员：admin / admin-demo
- 可在 backend/.env 设置 FAMILY_PASSWORD、ADMIN_PASSWORD。

当前仅用于本机课程开发，不应拿演示账号直接公开部署。管理员界面独立，但对应角色接口校验也在后端实施，不依赖隐藏按钮。

## AI 配置

管理端填写 HTTPS API 基础地址（通常以 /v1 结尾）、模型名称、API 密钥，配置保存到 backend/.env，不提交 Git。也可复制 backend/.env.example 为 backend/.env 手动填写后重启后端。

未配置时会显示状态或返回明确错误，不伪造模型回答。资料不足和超范围提示为系统规则提示，与模型生成回答区分。

## 测试

原测试已改为使用临时数据库，不再往演示数据库写入测试数据。新增权限隔离、知识审核/停用/历史、规则匹配、资料不足、未配置模型、核对及风险确认测试。自动化不等于完成课程系统测试文档；尚未实现项不可填写为通过。
