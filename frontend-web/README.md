# 药明白前端实现与联调说明

负责人为 wmx，覆盖家庭用户 UI 包和知识库管理 UI 包。功能范围按课程需求与概要设计，以下记录当前 Web 版实现和验收边界。

## 本地运行

在项目根目录首次执行 `setup-windows.cmd`，随后分别启动 `start-backend.cmd` 和 `start-frontend.cmd`。家庭端为 `http://127.0.0.1:5173/`，管理端为 `http://127.0.0.1:5173/admin`。接口文档为 `http://127.0.0.1:8000/docs`。在本目录可执行 `npm.cmd run build`。

Vite 将相对地址 `/api` 代理到 8000。家庭端和管理端独立保存登录令牌，后端负责角色权限检查。首轮 OCR 需要下载识别资源，图片本身在浏览器中处理。

## 当前实现

| 模块 | 已接入页面与行为 | 当前边界 |
| --- | --- | --- |
| 家庭端导航 | 竖屏单列，底部五项导航、首页快捷入口、功能子页返回来路 | 页面内导航状态保存在内存中 |
| 家庭成员 | 成员查看、弹窗新增与编辑、删除 | 药箱现有接口仍按成员名称关联 |
| 添加药品 | 按名称、别名或成分查询已发布知识；页面内浏览器图片 OCR、原文编辑、文字解析、演示样例、手工填写；核对后检查风险并确认入箱 | 低分辨率中文、小字和表格可能识别不全；成分取自已发布知识，唯一精确匹配时自动回填，也可从搜索结果选用；没有匹配时暂无法完成入箱 |
| 家庭药箱与风险 | 按成员筛选、药品详情、库存与位置编辑、零库存及过期标记、删除；成员药品组合风险及来源 | 保存库存或位置时，现有后端重置核对状态；完整编辑和重新核对待联调；特殊人群为知识提示 |
| 提醒和记录 | 设置、启停与删除提醒；今日服药确认和撤销；历史筛选；儿童喂药记录 | 到点自动通知及后台推送待接入；儿童记录按服务端当前时间保存，历史补录待接入 |
| 老人模式 | 大字号、成员切换、按时段查看今日用药、服药确认及撤销、查看药品；已核对药品可语音播报 | 依赖浏览器语音能力；联系家人页暂无电话拨打 |
| 用药知识与 AI | 知识检索、详情、来源、纠错反馈；AI 入口、药品上下文、多轮及历史 | 真实模型服务需配置并联调 |
| 知识库管理 | 药品知识和规则的草稿编辑、发布、停用、只读版本历史、纠错反馈和 AI 服务配置 | 课程资料需审核发布后才参与家庭端查询与规则匹配 |

## 接口对接

| 流程 | 当前契约 |
| --- | --- |
| 知识搜索与说明书解析 | `GET /api/knowledge/drugs?keyword=...` 返回已发布条目及成分。 `POST /api/instruction/parse` 接受 `ocr_text` 或 `sample_id` 二选一，返回结构化字段及 `missing_fields`。 |
| 入箱前检查 | `GET /api/members` 提供成员。向 `POST /api/interactions/check` 提交 `member_id`、`candidate_name`、`candidate_ingredients`。页面读取 `items`、`count`、`message`、`missing`；命中规则需用户确认。 |
| 保存与回查 | `POST /api/medicines` 使用 `owner` 成员名称，提交核对后的药名、成分、用量、频次以及 `confirmed`、`risk_accepted`。201 后回药箱可查看，409 清除旧报告并要求重新检查。现有 `PUT /api/medicines/{id}` 用于库存与位置修改。 |
| 提醒与记录 | `/api/reminders` 管理提醒，`GET /api/today` 返回今日状态，`/api/records` 提供确认、撤销和历史。儿童体温字段 `temperature` 按字符串提交。 |
| 角色与管理端 | `/api/auth` 提供登录和退出，管理端调用 `/api/admin/*`。以 HTTP 状态与 FastAPI `detail` 为失败依据，保存前端输入并展示反馈。 |

### 待跨包确认

- **药品编辑与重新核对（sjw、qhy、wzy）**。明确哪些字段修改需要重新核对、风险重算如何排除当前药品、何时保存核对状态与风险确认。当前名称关联迁移到 `member_id` 时，需同步接口和历史数据。
- **到点提醒（sjw、qhy）**。约定业务时区、触发事件、重复通知去重和后台推送方式，再联调页面状态。
- **儿童历史补录（sjw、qhy、wzy）**。约定实际服药时间字段、时区、可补录范围和查询行为。
- **规则覆盖（qhy、wzy）**。确认食物饮品及特殊人群匹配的资料来源、条件、结果和验收数据。
- **AI 联调（qhy、wmx）**。配置演示模型，验证真实回答、引用、多轮与异常提示。
- **多家庭隔离（sjw、qhy、wzy）**。如纳入验收，确定家庭身份、数据归属和越权响应。当前为本地单家庭演示。

跨包任务的补充验收步骤见[前端联调清单](../docs/前端联调清单.md)。

## OCR 回归样例

原始 WebP 位于 `test-fixtures/ocr/`，用于从「扫一扫」手动上传，上传原图后走 OCR，无图片专用预填。复测时在添加药品页选择图片，等待自动识别和解析，在核对弹窗核对字段。需要修正时可关闭弹窗，修改原文后重新解析。样例结果记录的是软件表现，用药信息须对照原说明书核对。

| 样例 | 当前复测结果 |
| --- | --- |
| [小柴胡颗粒说明书](test-fixtures/ocr/xiaochaihu-leaflet.webp) | 上传、识别、解析通过；测试图上的一次用量、频次、服用方式可回填。药名冲突、规格残缺留空，成分需匹配已发布知识。 |
| [布洛芬片说明书](test-fixtures/ocr/ibuprofen-leaflet.webp) | 在 Edge 从上传走到解析。解析可从带页眉杂字的标题回填「布洛芬片」。成分、规格和用法段识别不可靠，相关字段留空；儿童剂量表需人工核对。复测止于核对表。 |
